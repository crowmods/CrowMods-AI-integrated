# CrowMods AI — Phase 28: AI Community Manager

Adds a community-assistance control plane for channels and site discussions.

Capabilities:
- unified inbound message records
- FAQ/knowledge-base matching
- AI reply drafts
- moderation signal detection
- escalation queue
- human approval for public replies
- community analytics hooks

The system does not autonomously ban users, mass-DM people, manipulate
engagement, or impersonate moderators. High-impact moderation remains
human-approved.
