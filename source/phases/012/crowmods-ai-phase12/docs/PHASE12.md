# Phase 12 Notes

The analytics layer is intentionally privacy-conscious.

Recommended events:
- page_view
- release_view
- download_click
- download_started
- social_click
- campaign_published
- community_join
- favorite
- review_submitted
- revenue_event

Avoid collecting unnecessary personal data.

The recommendation engine is advisory. Keep human approval for:
- pricing changes
- financial transfers
- ad-account changes
- security configuration
- account permissions
- irreversible data deletion
