# CrowMods AI — Phase 22: Search & Discovery AI

Adds search and discovery capabilities for the public catalog.

Features:
- full-text search foundation
- category filters
- trending releases
- recently updated releases
- related-release recommendations
- popularity scoring
- search analytics
- discovery dashboard API

The recommendation logic is intentionally explainable and can later be
augmented with an AI ranking model. Do not infer sensitive personal traits or
use them for recommendations.
