# Phase 40 Notes

Media flow:

release
-> asset intake
-> metadata
-> AI alt text/caption
-> platform variants
-> human review
-> approved asset library
-> campaign/publishing queue

Recommended production media pipeline:
- private object storage;
- image dimension/format validation;
- image decompression limits;
- malware/content scanning where appropriate;
- generated object keys;
- immutable hashes;
- CDN delivery only after approval;
- short-lived signed upload/download URLs.

AI should not:
- fabricate official branding;
- impersonate third parties;
- remove ownership/watermarks from material you do not own;
- generate misleading claims about an app/game;
- publish assets without approval.

Only use screenshots, logos, artwork and promotional material that you created
or have permission to distribute.
