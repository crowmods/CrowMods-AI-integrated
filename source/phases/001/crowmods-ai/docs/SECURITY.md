# CrowMods Security Baseline

1. Uploaded APKs are untrusted and remain in quarantine until approved.
2. Never execute uploaded APKs.
3. Store secrets only in environment/secret-management systems.
4. Require MFA/passkeys for administrator access.
5. Apply least privilege to workers and integrations.
6. Keep public web, database, object storage, and workers logically separated.
7. Log authentication, authorization, upload, approval, and publishing events.
8. Maintain backups and test restoration.
9. Use official APIs/OAuth for external platforms.
10. Only distribute content you are authorized to redistribute.
