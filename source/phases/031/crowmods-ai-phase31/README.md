# CrowMods AI — Phase 31: Revenue & Monetization Engine

Adds a provider-neutral monetization control plane.

Supported revenue models:
- premium memberships
- subscriptions
- affiliate attribution
- sponsorship tracking
- digital-product sales

Includes:
- plans
- customer references
- subscription states
- payment event records
- invoices
- affiliate clicks/conversions
- revenue dashboard API
- webhook adapter boundary

Payment credentials and raw card data must remain with the payment provider.
Never store card numbers, CVVs, or payment authentication secrets in CrowMods.
