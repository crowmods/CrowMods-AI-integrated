# CrowMods AI — Phase 14: User Accounts + Premium Foundation

Adds a provider-neutral user account and membership foundation.

Features:
- user registration model
- password hashing helper
- role-aware account model
- premium membership records
- favorites
- download-history events
- notification preferences
- account dashboard API

Production must use a mature identity provider or thoroughly tested auth
implementation, MFA/passkeys, email verification, password reset, rate limits,
session revocation, and secure secret management.

Only distribute content you are authorized to distribute.
