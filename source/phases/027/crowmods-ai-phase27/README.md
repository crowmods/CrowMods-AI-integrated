# CrowMods AI — Phase 27: AI Social Strategy Engine

Adds an explainable social-strategy recommendation layer.

The engine recommends:
- suitable platforms
- content angles
- timing windows
- platform variants
- experiment ideas
- metrics to watch

It learns only from the campaign analytics available to the system and
does not infer sensitive personal characteristics.

Recommendations remain advisory. Publishing, account changes and financial
actions require the existing approval and authorization controls.
