# CrowMods AI — Phase 8: Discord Community AI

Adds a Discord integration foundation using the official Discord API/bot model.

Features:
- announcement payload generation
- configurable channel target
- welcome message template
- FAQ response templates
- moderation event rules foundation
- dry-run mode
- server-side bot token configuration

Production requires a real Discord bot, OAuth installation, least-privilege
permissions, durable moderation logs, and human escalation for uncertain cases.
