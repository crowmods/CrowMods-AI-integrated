# CrowMods Community AI

Recommended Discord capabilities:

## Welcome
- greet new members
- point to rules and support channels
- explain how to find releases

## FAQ
Use a curated knowledge base first. AI should answer only from approved
CrowMods documentation and escalate uncertain questions.

## Moderation
Detect and flag:
- repeated spam
- suspicious links
- impersonation
- abusive content
- excessive message bursts

Use a configurable policy engine. Do not let an AI model silently ban users
based only on an uncertain classification.

## Permissions
Use least privilege. Keep moderation, announcements, and administration
permissions separate where possible.
