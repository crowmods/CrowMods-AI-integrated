# CrowMods AI — Phase 29: AI Support & Knowledge Base

Adds a central, versioned knowledge base and retrieval layer.

Capabilities:
- articles and FAQs
- release-aware knowledge
- keyword search
- source citations
- AI answer drafts
- confidence scoring
- unresolved-question tracking
- knowledge-base admin

The answer engine is grounded in stored sources. It must not invent policies,
release features, security claims, or support outcomes.
