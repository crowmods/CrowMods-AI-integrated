# CrowMods AI — Phase 25: Discord Automation Engine

Adds a Discord publishing control-plane foundation.

Features:
- server/channel configuration
- AI release embeds
- buttons/links
- approval states
- scheduled publishing
- message tracking
- retry/failure fields
- analytics event hooks

The actual Discord connector is isolated behind an adapter. Use a bot/webhook
for servers you control and comply with Discord's developer and community
rules. Never automate spam, fake engagement, unsolicited DMs, or abuse.
