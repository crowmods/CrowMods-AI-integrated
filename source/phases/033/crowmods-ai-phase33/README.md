# CrowMods AI — Phase 33: Admin Command Center

Adds a centralized operations dashboard foundation.

It aggregates:
- release/approval status
- publishing queues
- community escalations
- knowledge-base health
- user/premium counts
- revenue
- analytics KPIs
- security/system health

The dashboard is read-oriented by default. Destructive actions should remain
behind explicit RBAC, confirmation, audit logging, and ideally step-up
authentication.
