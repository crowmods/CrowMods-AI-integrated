# Phase 24 Notes

Telegram flow:

approved release
-> AI post draft
-> image selection
-> human approval
-> queue
-> official Telegram Bot API
-> channel message
-> message ID recorded
-> analytics

Professional formatting can include:
- HTML/Markdown formatting;
- buttons linking to the official release page;
- approved artwork;
- version and changelog;
- concise call-to-action.

Avoid:
- unsolicited mass messaging;
- fake engagement;
- engagement manipulation;
- duplicate spam;
- unauthorized channel access;
- storing bot tokens in source code.

For Telegram Premium emojis/custom emoji, use only emoji/custom-emoji assets
that the bot/account is authorized to use and keep platform-specific formatting
inside the Telegram connector.
