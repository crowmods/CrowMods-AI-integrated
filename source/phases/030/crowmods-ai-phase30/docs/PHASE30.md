# Phase 30 Notes

Analytics flow:

website/events
-> platform events
-> campaign events
-> download events
-> revenue events
-> aggregate KPIs
-> explainable AI insights
-> growth experiments

Recommended production metrics:
- unique visitors;
- release-page views;
- download clicks;
- completed downloads;
- campaign impressions;
- clicks;
- conversion rate;
- returning visitors;
- community growth;
- revenue;
- refund/takedown rates where applicable.

Privacy:
- prefer anonymous session IDs;
- minimize data collection;
- define retention periods;
- restrict analytics access with RBAC;
- document cookies/consent where applicable;
- do not infer sensitive personal characteristics.

Revenue analytics should record verified transactions only. Never fabricate
revenue or conversion numbers.
