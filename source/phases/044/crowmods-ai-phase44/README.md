# CrowMods AI — Phase 44: AI Community Manager

Adds a defensive community-management foundation for connected channels.

Capabilities:
- inbound message intake
- message classification
- FAQ/knowledge-base answer suggestions
- moderation queue
- spam/risk signals
- member/community metrics
- announcement drafts
- human approval for public actions
- audit events
- escalation workflow

The AI is advisory by default. It should not silently ban users, delete
content, impersonate people, or bypass platform moderation controls.
Platform-specific moderation actions must use official APIs and documented
permissions.
