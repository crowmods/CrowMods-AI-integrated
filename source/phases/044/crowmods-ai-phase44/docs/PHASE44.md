# Phase 44 Notes

## Community loop

platform message
-> connector
-> community intake
-> classification
-> FAQ/knowledge lookup
-> answer/moderation suggestion
-> approval or escalation
-> official connector action
-> audit
-> analytics

## AI responsibilities

AI may:
- classify messages;
- draft answers;
- summarize recurring questions;
- identify likely spam;
- prioritize support;
- suggest escalation;
- summarize community sentiment.

AI should not independently:
- permanently ban members;
- expose personal information;
- impersonate administrators;
- fabricate official statements;
- bypass platform moderation;
- retaliate against critics;
- mass-message members.

## Knowledge base

The next useful layer is a verified knowledge base containing:
- release information;
- supported devices/versions;
- download policies;
- refund/support policies;
- community rules;
- official links;
- known issues.

Answers should cite or link to authoritative CrowMods content when possible.

## Moderation

Use platform-provided moderation capabilities where available. Preserve
appeals and human review for consequential actions.
