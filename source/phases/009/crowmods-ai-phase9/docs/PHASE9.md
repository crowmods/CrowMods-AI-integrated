# Phase 9 Notes

This phase deliberately does not perform live posting to every social
network. Each platform has different API products, permissions, quotas,
OAuth flows, media requirements, and policy constraints.

The engine creates:
- one campaign ID;
- platform-specific content;
- connection state;
- per-platform queue state.

Next, add individual official connectors with separate OAuth credentials.
Do not automate website browsers, bypass rate limits, create fake accounts,
or mass-post to unrelated communities.
