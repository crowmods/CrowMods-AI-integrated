# CrowMods AI — Phase 21: Public Release Website

Adds a public-facing release catalog foundation.

Features:
- homepage API
- search
- category filtering
- release detail API
- version information
- download endpoint foundation
- related releases
- SEO metadata
- sitemap foundation
- download analytics event

The download endpoint is intentionally a controlled placeholder. Production
should use private object storage and short-lived signed URLs after all
authorization, approval, and safety checks pass.
