# CrowMods AI — Phase 26: Multi-Social Campaign Engine

Adds a provider-neutral campaign orchestration layer.

Supported platform adapters:
- Telegram
- Discord
- X
- Instagram
- Facebook
- Reddit
- YouTube
- WhatsApp
- LinkedIn

The engine creates platform-specific drafts from one approved release,
tracks approval/scheduling/publishing state, and records analytics.

Actual platform connectors must use official APIs or authorized integrations.
No connector is designed for spam, fake engagement, unsolicited messaging,
rate-limit bypassing, or account evasion.
