# CrowMods AI — Phase 39: AI Release Intelligence

Adds a release-intelligence layer that turns verified upload metadata into
structured, reviewable release information.

Capabilities:
- release metadata extraction boundary
- app/game classification
- version normalization
- changelog generation from supplied facts
- category/tag suggestions
- SEO metadata
- release-page copy
- social-content drafts
- confidence and source tracking
- human approval before publication

The AI must not invent version numbers, features, compatibility, licensing,
security claims, or release notes. Unknown fields remain unknown until verified.
