# Phase 41 Notes

Website release flow:

approved release intelligence
+ approved media
+ verified release storage
-> page model
-> SEO
-> structured data
-> gallery
-> download section
-> related releases
-> review
-> publish

## SEO

The builder provides:
- title;
- description;
- canonical URL boundary;
- structured data;
- clean slug.

Validate generated metadata before publication.

## Download security

The page should never expose permanent storage credentials or direct private
bucket paths. At publish/request time, the backend should generate a short-lived
signed URL for an approved release.

## AI boundaries

AI can draft copy, organization and metadata.

AI cannot establish:
- ownership;
- licensing rights;
- authenticity;
- security guarantees;
- compatibility beyond verified facts.

Those must come from authoritative sources or human review.

## Content policy

Only publish applications, games, mods, screenshots and other media that you
are authorized to distribute and that comply with applicable laws and the
rules of the services where they are promoted.
